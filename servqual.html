Website Quality Assessment System

Website Evaluation Using SERVQUAL Method

Project Overview

Website Quality Assessment System merupakan aplikasi berbasis web yang dikembangkan sebagai proyek tugas akhir untuk mengevaluasi kualitas Website Layanan Pengaduan Disdukcapil Kabupaten Sijunjung menggunakan metode SERVQUAL. Sistem ini membantu admin dalam mengelola data responden, mengolah hasil kuesioner, menghitung nilai GAP antara persepsi dan harapan, serta menampilkan hasil evaluasi secara otomatis dalam bentuk tabel dan laporan.

Research Method

Metode yang digunakan adalah SERVQUAL (Service Quality) untuk mengukur kualitas website berdasarkan lima dimensi yaitu:

  • Tangible
  • Reliability
  • Responsiveness
  • Assurance
  • Empathy
