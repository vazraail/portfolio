UI Design Website Absensi CX

Perancangan Antarmuka Website Absensi menggunakan Figma

Tentang Proyek

UI Design Website Absensi CX merupakan proyek perancangan antarmuka (UI) untuk sistem absensi anggota UKM-IT Cybernetix Universitas Putra Indonesia "YPTK" Padang. Desain dibuat menggunakan Figma dengan mengutamakan tampilan yang modern, sederhana, serta mudah digunakan. Pada proyek ini saya merancang halaman Login dan Home Dashboard sebagai konsep awal pengembangan sistem absensi digital.

Tujuan Pengembangan

Proyek ini dikembangkan sebagai bagian dari kontribusi dalam mendukung digitalisasi administrasi organisasi melalui perancangan antarmuka Website Absensi. Fokus utama desain adalah memberikan pengalaman pengguna yang sederhana, nyaman, dan mudah dipahami sehingga proses absensi anggota dapat dilakukan secara lebih efektif.
