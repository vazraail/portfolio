E-Commerce Skincare

Website Penjualan Produk Skincare Berbasis Web

Tentang Proyek

Website Skincare merupakan aplikasi berbasis web yang dikembangkan untuk mempermudah proses penjualan produk skincare secara online. Sistem ini menyediakan fitur pengelolaan produk, autentikasi pengguna, serta proses pembelian sehingga pengguna dapat melihat informasi produk dengan lebih mudah dan melakukan transaksi secara efisien.

Tujuan Pengembangan

Proyek ini dikembangkan sebagai media pembelajaran dalam membangun website penjualan menggunakan PHP dan MySQL. Selain itu, website ini bertujuan memberikan pengalaman pengguna yang lebih mudah dalam mencari informasi produk serta melakukan pembelian secara online.

Galeri Proyek

Beberapa tampilan berikut merupakan cuplikan antarmuka website yang menampilkan fitur-fitur utama dan alur penggunaan aplikasi. Tidak seluruh halaman ditampilkan agar penyajian proyek tetap ringkas dan mudah dipahami.
